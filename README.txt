KHUSH PREMIUM LOADER — starter Android project

Package: com.khush.viploader
Minimum Android: 11 (API 30)
Compile/target SDK: 36
Theme: Red Devil (black/red)
Login: license-key field only

IMPORTANT:
This is a UI starter project. The Verify License button is deliberately a demo
placeholder. It does NOT authenticate, activate, bind devices, or check expiry.
Those features require a secure HTTPS backend and an admin service. Do not put
admin secrets or signing credentials in the Android app.

Phone build:
1. Install a reputable Android IDE that supports Gradle projects (for example,
   AndroidIDE, if available for your device).
2. Extract this ZIP.
3. Open the extracted project folder in the IDE and allow Gradle sync.
4. Build the debug APK from the IDE's Build menu.

SDK 36 must be installed by the IDE. Android 17 compatibility should be tested
against the final Android 17 SDK when available in your build environment.
